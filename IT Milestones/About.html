About This Project & Author

This web application was designed and developed as part of coursework for IT 3203 (Web Development and Evolution) at Kennesaw State University. The repository serves as an ongoing platform to document research findings on web server architectures, cloud scalability, energy optimization, and decentralized peer-to-peer web hosting.
