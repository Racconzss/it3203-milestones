Abstract & Executive Overview

Web servers are the fundamental backbones of the World Wide Web, responsible for hosting application files, executing dynamic scripts, and processing incoming HTTP/HTTPS requests from client browsers around the globe. This project explores how web server infrastructure has evolved from isolated physical servers to virtualized cloud platforms, green micro-servers, IoT web nodes, and decentralized peer-to-peer networks.

Core Research Objectives

  • Request Processing & Overload: Managing bursty web traffic, packet filtering, and maintaining Service Level Agreements (SLAs).
  • Energy Optimization: Balancing Dynamic Voltage/Frequency Scaling (DVFS) and dynamic server provisioning in high-density data centers.
  • Decentralized & Embedded Systems: Deploying microcontroller web servers, IoT sensors, and hybrid pWeb architectures.
